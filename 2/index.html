首月结束后，不续费会怎样？
首月到期后，AI 模型访问功能将暂停，但设备本身和 OpenClaw 基础系统仍可正常使用。您可以随时在 OpenClaw 管理面板中选择任意订阅方案进行续费，立即恢复访问权限。
Token 是怎么计算的？支持哪些模型？
Token 按所有模型的输入+输出合计计算。1M（100万）Token 大约相当于 75 万汉字的对话量。目前接入模型包括 ChatGPT（OpenAI）、Gemini（Google）、Kimi（月之暗面），后续将持续增加更多模型。
追加购买的 Token 有有效期吗？
追加购买的 Token 当月有效，未使用完的部分在自然月结束后清零，不累积到下月。建议根据实际使用量合理购买，避免浪费。企业版用户可联系客服了解 Token 滚存政策。
